# 🏠 탐비 블로그 스튜디오

드라마·자동차·지원금경제, **세 블로그를 한 화면에서** 쓰는 탐비를 위한 모바일 우선 웹 대시보드입니다.
폰에서 링크만 열면 바로 쓰고, 홈 화면에 추가하면 앱처럼 열립니다.

- **앱 주소**: https://miae0207-cmd.github.io/tambi-studio/
- **소재 데이터**: [`topics.json`](topics.json) — 이 파일만 고치면 앱의 소재 목록이 바뀝니다.
- 사진은 **공식 홈페이지·공식 유튜브에서 직접 캡처**해서 씁니다. 기사 사진(보도스틸) 링크는 앱에서 모두 뺐습니다.

### 🎬 움짤 만들기 (이미지 탭)

짧은 영상(MP4·MOV·WebM)을 골라 원하는 구간만 GIF로 굽습니다. 영상은 브라우저 안에서만 처리되고 서버로 가지 않습니다.

- 구간: 시작·끝 슬라이더로 **최대 6초**(기본 4초). 길이와 프레임 수를 실시간으로 보여줍니다.
- 크기: `640px(추천)` / `480px(가벼움)` / `800px(선명함)`, 프레임: `8fps` / `10fps(기본)` / `12fps`.
- 워터마크: `달래쨘` / `달래의 행복나라 여행기♡` / 직접 입력, 위치 없음·우하단·좌하단·우상단.
- 변환은 `gif-maker.js` 한 파일에서 끝납니다 — 외부 CDN 없이 중앙값 분할 팔레트 양자화 + GIF89a LZW 인코더 + 프레임 차분(바뀐 픽셀만 기록)까지 직접 구현. 진행률 %를 보여주고, 완성되면 움직이는 미리보기·용량·`💾 GIF 저장`(`달래쨘_YYYYMMDD_HHMM.gif`)이 나옵니다.

### 소재 탭

- 상단 **3블로그 필**로 전환합니다. 선택은 기기에 저장돼 다음에 열면 그 블로그로 시작합니다.
- **드라마**: 방영중/과거작 필터, 장르·작가·요약, 바로 쓸 제목, **홈판 제목(작품명 없이)**, 공홈 스틸컷·공식 유튜브 직링크, 접이식 줄거리·하이라이트·비하인드.
  - 과거작 카드는 **탐비 블로그(miae0207)에 아직 없는 작품**만 넣었습니다. 이미 다룬 작품은 `data_drama.py`에 보관하고 목록에서만 뺐으며, 근거 글 목록은 `build/written_dramas.json`에 남겨 두었습니다.
- **자동차**: 신차·리콜·세금·정비·보조금·초보운전 필터. 카드마다 *무슨 일인지 → 왜 중요한지 → 핵심 숫자 → 어려운 용어 없이 핵심만 → 쉬운 말 사전 → 제목 3개 → 공식 출처*.
- **지원금·경제**: 지원금·세금·소상공인·생활경제 필터. 카드마다 **대상 / 신청기간 / 혜택 / 방법**을 표로 먼저 보여주고, 제목과 공식 신청 링크를 붙였습니다.

### 홈판 제목 공식 (제목 탭)

달래쨘 블로그에서 실제로 통한 제목은 두 모양입니다. 생성기도 이 모양으로만 뽑습니다.

| 상태 | 공식 | 예 |
|---|---|---|
| 과거·종영작 (작품명 숨김) | `'인용 훅'` + 성과·방송사·배우 + `드라마` | `'시청률은 2%대였는데..' 8주 동안 시청자 공감을 쌓은 JTBC 드라마` |
| 방영중 (작품명 포함) | `[작품명] [회차], [한 줄 훅]` | `100일의 거짓말 10회, 터진 건 폭탄만이 아니었다` |

숫자는 **확인한 값만** 넣습니다. 제목 탭의 `➕ 숫자·성과 넣기`에 인용 훅·성과 문장·방송사·배우를 적으면 그대로 공식에 들어가고, 비워두면 숫자를 만들지 않는 안전한 훅으로 대체합니다.

상단에는 오늘의 발행 목표(기본 3편) 진행바와 `+1 발행` / `−1`, 상태 배지, 최근 7일 기록이 있습니다.

## 통계 리포트 데이터 바꾸는 법 (📊 탭)

지금 들어 있는 값은 네이버 블로그 관리 > 통계에서 받은 **실제 기록**입니다(2026-11-13 ~ 11-19, 조회 74,511 · 방문자 70,085).
`stats.json` 한 파일만 고치면 됩니다. 화면의 KPI(한 주 조회수·하루 평균·최다 조회일·1위 글 조회수)와 글 유형별 도넛은 목록 숫자에서 자동으로 계산됩니다.

- `daily` — 요일·날짜·조회수 7줄
- `sources` — 홈판 / 검색 / 블로그 안 / 엔터판·기타 유입 비율(합 100)
- `posts` — 글 제목, 유형(`home` 홈판용(과거작) / `air` 방영작 / `issue` 이슈 / `review` 리뷰), 7일 합산 조회수. **조회수 많은 순으로** 넣습니다.
- `period` — `label`(예: `11/13 ~ 11/19 최근 7일 리포트`), `note`(예: `1주 기록`)
- `blogName` / `source` — 머리말에 그대로 붙는 블로그 이름과 출처 문구
- 실제 숫자를 넣으면 `sample`은 `false`, `banner`는 빈 값으로 둡니다(샘플 안내 배너가 사라집니다).
- `stats.json`과 `stats-data.js`는 `build/build_stats.py`가 통계 추출본에서 함께 만들어 줍니다(숫자를 손으로 옮기지 않음). `updated` 시각도 그 스크립트에서 바꿉니다.

### 크리에이터 어드바이저 값(`advisor`)

네이버 **크리에이터 어드바이저**(creator-advisor.naver.com) 화면값입니다. `build/build_stats.py`가 `handoffs/📊-크리에이터-어드바이저-통계-탭-반영/advisor_raw.json`을 읽어 `advisor` 블록으로 넣고, 7일 합계·일평균은 일별 값에서 계산합니다(11/13~11/19 합계 93,971원 / 일평균 13,424원으로 검산됨).

- `revenue` — 최근 7일 일별 예상수익(`daily`), 7일 합계·일평균, 어제 값과 전일 대비, 광고 노출·클릭·클릭률
- `traffic` — 어제 조회수·메인 유입·검색 유입
- `rising` — 어제 급상승 콘텐츠(제목·작성일시·조회수·증가분/`is_new`)
- `audience` — 기기·성별 비율, `age_band`(45~54세 비중), `age_top`(상위 연령×성별 4칸)
- `searchTerms` — 주제(드라마·방송·자동차·경제)별 인기 유입 검색어. **내 블로그가 아니라 네이버 블로그 전체 기준**입니다
- `lastWeek` — 지난주 돋보였던 콘텐츠 5건(제목·블로그명·`https://blog.naver.com/...` 직링크). 앱에서 제목을 누르면 원문 글이 열립니다
- `mainTop` — 네이버 메인 유입 TOP20의 제목·`url`(전체 기준, 홈판 벤치마킹용). `url`은 크리에이터 어드바이저 목록의 `a` 태그에 걸린 **원문 `https://blog.naver.com/{블로그ID}/{logNo}`** 이고, 앱에서 제목을 누르면 그 글이 새 탭에 열립니다

## 저장되는 것

목표 편수, 발행 기록, 저장한 제목, 체크리스트, 선택한 블로그는 **그 브라우저(기기)의 localStorage**에 저장됩니다. 서버로 보내지 않습니다. 브라우저 데이터를 지우면 함께 사라집니다.

## 소재 업데이트하는 법

`topics.json`을 고치고 `updated` 시각을 바꾼 뒤, 같은 내용을 `topics-data.js`(`window.TOPICS_FALLBACK = {...};`)에도 반영해 커밋합니다. 앱은 열릴 때 `topics.json`을 새로 받아오고, 실패하면 내장 스냅샷으로 보여줍니다(오프라인 대비).

```json
{
  "updated": "2026-11-19T22:31:24+09:00",
  "label": "2026년 11월 넷째 주",
  "version": 3,
  "blogs": [
    { "id": "drama", "icon": "📺", "label": "드라마", "key": "topics", "filters": [] },
    { "id": "car", "icon": "🚗", "label": "자동차", "key": "car", "filters": [] },
    { "id": "money", "icon": "💰", "label": "지원금·경제", "key": "money", "filters": [] }
  ],
  "topics": [ /* 드라마 카드 */ ],
  "car": [ /* 자동차 카드 */ ],
  "money": [ /* 지원금·경제 카드 */ ]
}
```

## 파일 구조

```
index.html      화면
style.css       파스텔 라벤더 디자인
app.js          UI 로직(목표·3블로그 소재·생성기·이미지·저장함)
engine.js       제목/각도 생성 엔진(한국어 조사 처리, 자극어 필터, 길이 판정)
image-editor.js 사진 편집기(콜라주·자르기·모자이크·워터마크·저장)
image-editor.css 이미지 탭 스타일
gif-maker.js    🎬 움짤 만들기 — 영상→GIF (팔레트 양자화 + GIF89a LZW 인코더 내장)
topics.json     소재 데이터(라이브) — topics / car / money
topics-data.js  소재 데이터(내장 스냅샷)
manifest.json   홈 화면 추가용
icon.svg        앱 아이콘
```
