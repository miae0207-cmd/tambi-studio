# 🏠 탐비 블로그 스튜디오

드라마·방송 블로그를 쓰는 탐비를 위한 **모바일 우선 웹 대시보드**입니다.
폰에서 링크만 열면 바로 쓰고, 홈 화면에 추가하면 앱처럼 열립니다.

- **앱 주소**: https://miae0207-cmd.github.io/tambi-studio/
- **소재 데이터**: [`topics.json`](topics.json) — 이 파일만 고치면 앱의 소재 목록이 바뀝니다.
- 사진은 **공식 홈페이지·공식 유튜브에서 직접 캡처**해서 씁니다. 기사 사진(보도스틸) 링크는 앱에서 모두 뺐습니다.

## 무엇이 들어 있나

| 탭 | 하는 일 |
|---|---|
| 💡 소재 | 방영중 4 + 과거작 18 = 22개 카드. 장르·작가·요약, 바로 쓸 제목, **홈판용 제목(작품명 없이)**, **공홈 스틸컷·공식 유튜브 직링크**, 접이식 **줄거리 순서 · 하이라이트**, **비하인드·특이점**, 작품명·배우·채널 검색 |
| ✍️ 제목 | 방영중(작품명 포함) / 과거작(작품명 숨김) 2모드 제목·각도 생성기. 18~32자 적정 길이 배지, 자극어(충격·경악 등) 자동 제외, 원탭 복사·저장 |
| 🖼 이미지 | 작품명 하나로 **방송사 공홈 포토**와 **공식 유튜브 클립**만 찾아갑니다 + 홈판 체크리스트 |
| 💗 저장함 | 저장한 제목 모아보기(과거작은 작품명 메모 함께), 복사·삭제 |

상단에는 오늘의 발행 목표(기본 3편) 진행바와 `+1 발행` / `−1`, 상태 배지(`🌱 첫 글 기다리는 중` → `✍️ 열일 중` → `☕ 목표 달성! 휴식 중`), 최근 7일 기록이 있습니다.

## 저장되는 것

목표 편수, 발행 기록, 저장한 제목, 체크리스트는 **그 브라우저(기기)의 localStorage**에 저장됩니다. 서버로 보내지 않습니다. 브라우저 데이터를 지우면 함께 사라집니다.

## 소재 업데이트하는 법 (매일)

`topics.json`의 `topics` 배열에 카드를 추가하거나 고치고 `updated` 시각을 바꿔 커밋하면 됩니다. 앱은 열릴 때 `topics.json`을 새로 받아오고, 실패하면 `topics-data.js`의 내장 스냅샷으로 보여줍니다(오프라인 대비).

```json
{
  "updated": "2026-11-20T09:00:00+09:00",
  "label": "2026년 11월 넷째 주",
  "topics": [
    {
      "id": "work-slug",
      "status": "airing",                 // "airing" | "past"
      "work": "작품명",
      "channel": "tvN",
      "year": "2026",
      "genre": "시대극 · 첩보 로맨스",
      "slot": "토일 밤 9:10",
      "cast": "배우 · 배우",
      "metric": "시청률·화제성 한 줄",
      "heat": "hot",                       // "hot" | "warm"
      "why": "왜 지금 홈판에서 클릭되는지 2~3문장",
      "angles": [{ "icon": "🔎", "text": "글 각도" }],
      "titles": ["작품명 포함(방영중) / 작품명 없이(과거작) 제목"],
      "homefeed": ["비하인드·특이점을 살린 홈판용 제목 — 작품명 없이"],
      "keywords": ["12회", "정체"],
      "imageQuery": "검색에 쓸 작품명",
      "officialPhotoUrl": "https://…",     // 실제로 열리는 공식 포토 페이지만. 없으면 null
      "officialPhotoLabel": "tvN 현장포토",
      "officialPhotoNote": "공홈 포토가 없을 때 안내 문구",
      "officialYoutubeUrl": "https://www.youtube.com/@tvNdrama_official/search?query=…",
      "officialYoutubeName": "tvN DRAMA",
      "timeline": [{ "range": "1~4회", "text": "줄거리 순서" }],
      "highlights": [{ "ep": "12회", "text": "주요 장면" }],
      "behind": [{ "label": "캐스팅", "text": "확인된 비하인드만" }]
    }
  ]
}
```

`officialPhotoUrl`은 **HTTP 200으로 열리는 방송사 공식 페이지만** 넣습니다. 확인되지 않으면 `null`로 두면 카드에 `공홈 포토 없음 → 유튜브 캡처 추천` 안내가 뜹니다.
`behind`에는 확인된 사실만 넣습니다(추측·창작 금지).

`topics.json`을 고친 뒤에는 `topics-data.js`도 같은 내용으로 갱신하면 오프라인에서도 최신 소재가 보입니다.

## 파일 구조

```
index.html      화면
style.css       파스텔 라벤더 디자인
app.js          UI 로직(목표·소재·생성기·이미지·저장함)
engine.js       제목/각도 생성 엔진(한국어 조사 처리, 자극어 필터, 길이 판정)
topics.json     소재 데이터(라이브)
topics-data.js  소재 데이터(내장 스냅샷)
manifest.json   홈 화면 추가용
icon.svg        앱 아이콘
```
